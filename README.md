# 📊 Data Vis App

An interactive data visualization web app built with Python, Streamlit, and Pandas.

## What it does
- Upload any CSV file
- Pick your X and Y axis columns
- Visualize your data as a Bar graph or Line graph
- Reset and explore different combinations

## Built With
- Python
- Streamlit
- Pandas

## How to Run
1. Install dependencies:
   pip install streamlit pandas
2. Run the app:
   streamlit run datavisapp.py
